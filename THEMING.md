# Site appearance

Administrators can select a primary color preset and add site-wide CSS in Site Settings. These settings are stored in the database and survive application updates when the database is preserved. CSS is applied after the built-in styles and can affect any page or load external resources; use trusted CSS only. To recover from CSS that hides the settings controls, open the settings page with `?disable_custom_css=1`, clear or fix the CSS, and save. A custom Content Security Policy may block inline styles.
