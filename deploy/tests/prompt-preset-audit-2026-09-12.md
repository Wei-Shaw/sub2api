## 过滤边界与扩展方法

- 开关默认关闭，缺少旧配置时仍关闭。关闭时请求体逐字节保持原样。
- 开启后保存副本只保留用户、助手或模型的消息正文、必要角色和多模态内容；移除系统与开发者消息、工具调用与结果、推理、客户端元数据、请求参数以及消息级元数据。媒体协议只保留可审阅的文本提示字段，不保留网址或编码后的媒体载荷。
- 当系统或开发者指令中识别到 Codex 或 Claude Code 身份时，处理用户文本开头的完整、已知封装：Codex 的 AGENTS.md 指令和 environment_context，以及 Claude 的 system-reminder。不递归修改工具结果或任意引用文档。
- 不使用模型名称判断代理身份，代理与模型提供商分开处理。新增代理在 agentPresetRules 中添加经真实请求验证的身份和区块规则；特殊协议封装在 filterPresetEnvelope 中扩展，并添加正反例。
- 位于用户消息中但无法识别为代理预设的文本和多模态内容继续保留，避免误删真实交互；非法 JSON 无法安全解析时保持原文。只有位于文本开头且身份匹配、边界完整的代理预设区块会从用户正文中移除。
- 只影响提示词记录的新请求正文；历史记录、请求头开关、响应内容、上游请求和独立的安全审计不因该开关被改写。
