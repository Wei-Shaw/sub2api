## 支持的支付方式

| 服务商 | 前台支付方式 | 结算币种 | 用户如何付款 |
|--------|------------|---------|------------|
| **SePay** | 越南银行转账 | VND（固定） | 扫描 VietQR 码，或复制银行信息手动转账。SePay 监听商户银行账户，收到匹配入账后推送 webhook。 |
| **NOWPayments** | 加密货币 | 法币计价（默认 USD），买家用任意币种支付 | 跳转到 NOWPayments 托管收银页；币种选择与汇率倒计时由 NOWPayments 负责。 |

> 每个服务商只对应一种前台支付方式，因此**支付类型与服务商 key 是同一个字符串**（`sepay`、`nowpayments`），不存在别名或渠道路由需要配置。

> 支付渠道的安全性、稳定性及合规性请自行鉴别，本项目不对任何第三方支付服务商做担保或背书。

## 快速开始

1. 进入管理后台 → **设置** → **支付设置**
2. 开启 **启用支付**
3. 配置基础参数（金额区间、订单超时、手续费率）
4. 在 **服务商管理** 中添加至少一个服务商实例并启用
5. 若通过 SePay 售卖以美元计价的套餐，务必设置 **USD → VND 汇率**（见[币种与金额](#币种与金额)）
6. 在服务商自己的后台登记 webhook 地址（见 [Webhook 配置](#webhook-配置)）

## 系统设置

在管理后台 **设置 → 支付设置** 中配置：

### 基础设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| **启用支付** | 支付系统总开关 | 关闭 |
| **商品名前缀 / 后缀** | 拼接发送给服务商的商品描述 | - |
| **最小金额** | 单笔最小充值金额 | 1 |
| **最大金额** | 单笔最大充值金额（留空表示不限） | - |
| **每日限额** | 单用户每日累计限额（留空表示不限） | - |
| **订单超时** | 订单超时时间，单位分钟（最小 1） | 30 |
| **最大待支付订单数** | 单用户同时进行中的订单上限 | 3 |
| **充值手续费率** | 在订单金额之上加收的百分比，0–100，最多 2 位小数 | 0 |
| **余额充值倍率** | 每单位实付到账的额度，必须大于 0（如 `1.1` 表示多赠 10%） | 1 |
| **USD → VND 汇率** | 通过 SePay（越南盾通道）收款时把美元价格换算为盾；`0` 表示关闭换算 | 0 |
| **负载均衡策略** | 选择服务商实例的策略 | 轮询 |
| **禁用余额支付** | 禁止用账户余额购买套餐 | 关闭 |

### 前台可见支付方式

结算页只有在**同时满足**以下两点时才展示某个方式：

- 该方式（`sepay` / `nowpayments`）在启用的支付类型列表中；
- 至少有一个**已启用**且能接受该订单金额的同 key 服务商实例。

启用类型列表留空时，回退为「按已启用的服务商实例展示」。

### 负载均衡策略

| 策略 | 说明 |
|------|------|
| **轮询**（默认） | 按顺序轮流分配订单 |
| **最小金额优先** | 优先选择当日累计金额最低的实例 |

### 取消频率限制

防止用户反复创建并取消订单：

| 设置项 | 说明 |
|--------|------|
| **启用限制** | 开关 |
| **窗口模式** | 滑动窗口 / 固定窗口 |
| **时间窗口** + **单位** | 窗口长度，按分钟或小时 |
| **最大取消次数** | 窗口内允许的取消次数 |

### 帮助信息

| 设置项 | 说明 |
|--------|------|
| **帮助图片** | 客服二维码或帮助图（支持上传） |
| **帮助文字** | 展示在支付页面的说明文字 |

## 币种与金额

面板内所有价格——套餐价格与余额充值——都以 **USD** 表示。实际扣款币种取决于实例：

- **NOWPayments** 按实例配置的币种（默认 USD）生成账单，买家用任意币种支付。
- **SePay** 只收 **VND**。把美元数字原样发给越南盾通道会少收约四个数量级，**USD → VND 汇率** 就是用来换算的。

> **汇率为 `0`（未设置）时不做换算，美元数字会被当作越南盾金额收取。** 启用 SePay 实例前请先设置汇率。

其他金额规则：

- 手续费率在订单金额之上计算，得出应付金额。
- 到账额度 = `实付金额 × 余额充值倍率`，保留 2 位小数。
- VND 是零小数币种：盾金额会取整到整数盾后再发给银行。

## 服务商配置

在 **服务商管理 → 添加服务商** 中选择类型。保存**启用状态**的实例时会校验配置，缺失或不可用的字段会直接在弹窗中报错，而不是等到下单时才失败。

### SePay

SePay 是越南银行账户的对账服务，**没有「创建支付」接口**：Sub2API 生成一段 VietQR 负载，预填向你的银行账户的转账，并把订单号作为转账备注；SePay 在账户收到匹配入账后推送 webhook。

| 参数 | 说明 | 必填 |
|------|------|------|
| **银行账号**（`accountNumber`） | SePay 监听的商户账号 | 是 |
| **银行代码**（`bankCode`） | 银行短代码，如 `MB`、`VCB`、`TCB`、`ACB` | 是（未填 BIN 时） |
| **Napas BIN**（`bankBin`） | VietQR 使用的六位银行标识。银行代码不被识别时填写；同时填写时以 BIN 为准 | 否 |
| **账户名**（`accountName`） | 展示在手动转账信息里的收款人姓名 | 否 |
| **API Key**（`apiKey`） | SePay webhook 上配置的共享密钥。`Authorization` 头不匹配的回调会被拒绝 | 是 |
| **用户 API Token**（`apiToken`） | 用于轮询 SePay 交易列表。不配置时订单只能靠 webhook 确认 | 否 |

SePay 后台设置步骤：

1. 绑定用于收款的银行账户
2. 创建 webhook，地址为 `https://your-domain.com/api/v1/payment/webhook/sepay`
3. 设置 webhook 的 API Key，并把同一个值填入实例的 **API Key**
4. （可选）创建用户 API Token 并填入 **用户 API Token**，让待支付订单也能通过轮询对账

### NOWPayments

NOWPayments 是加密货币网关。Sub2API 创建**托管账单（invoice）**并把用户引导到该页面。

| 参数 | 说明 | 必填 |
|------|------|------|
| **API Key**（`apiKey`） | NOWPayments API Key | 是 |
| **IPN Secret**（`ipnSecret`） | 校验每次 IPN 回调的 HMAC-SHA512 签名 | 是 |
| **支付币种**（`currency`） | 账单计价法币：USD、EUR、VND、SGD、AUD、GBP | 否（默认 USD） |
| **API 基础地址**（`apiBase`） | 覆盖接口地址 | 否（默认 `https://api.nowpayments.io/v1`） |

NOWPayments 后台设置步骤：

1. 在 **Settings → Payments** 生成 API Key
2. 将 IPN 回调地址设为 `https://your-domain.com/api/v1/payment/webhook/nowpayments`
3. 生成 IPN Secret 并填入实例的 **IPN Secret**

## 服务商实例管理

同一类型可以创建**多个实例**，用于负载均衡与风控：

- **多实例负载均衡** — 按轮询或最小金额优先分配订单
- **独立限额** — 每个实例有各自的单笔上下限与每日限额；超限实例在选择时自动跳过
- **独立开关** — 单独启用/停用实例，互不影响
- **支付模式** — `qrcode` 在站内渲染支付负载，`redirect` 跳转到服务商托管页。SePay 属于二维码流程，NOWPayments 属于跳转流程
- **排序** — 拖拽调整实例顺序

### 安全护栏

实例仍有进行中订单（`PENDING`、`PAID`、`RECHARGING`）时，以下操作被拒绝，因为这些订单是按旧的商户身份创建的：

| 操作 | 存在进行中订单时是否阻止 |
|------|------------------------|
| 删除实例 | 是 |
| 停用实例 | 是 |
| 移除已支持的支付类型 | 是 |
| 修改 SePay 的 `apiKey`、`apiToken`、`accountNumber`、`bankCode`、`bankBin` | 是 |
| 修改 NOWPayments 的 `apiKey`、`ipnSecret`、`apiBase`、`currency` | 是 |

密钥类字段（`apiKey`、`apiToken`、`ipnSecret`）不会被管理接口返回，编辑弹窗中显示为空；保存时留空表示保持原值不变。

## Webhook 配置

回调是订单确认的唯一依据。两个回调端点均为公开端点（无会话鉴权），由自身完成请求验证。

### 回调地址

| 服务商 | 回调路径 | 鉴权方式 |
|--------|---------|---------|
| **SePay** | `https://your-domain.com/api/v1/payment/webhook/sepay` | `Authorization: Apikey <apiKey>`（同时兼容 `Bearer` 前缀） |
| **NOWPayments** | `https://your-domain.com/api/v1/payment/webhook/nowpayments` | `x-nowpayments-sig` — 以 IPN Secret 为密钥、对排序后的 JSON 体做 HMAC-SHA512 |

添加实例时系统会根据站点域名自动生成回调地址，确认域名无误后到服务商后台登记即可。

### 注意事项

- 使用 **HTTPS**，并确保防火墙放行支付平台的回调请求。
- 与我们无关的事件会被直接 ack 并忽略：转出交易、备注中没有可识别订单号的入账（SePay），以及 `waiting`、`confirming` 等非终态（NOWPayments）。
- SePay **仅凭转账备注**匹配订单。用户改写转账备注会产生无法匹配的入账，需要人工对账处理。
- 回调验证通过后自动到账 / 开通订阅，无需人工操作。

## 支付流程

```
用户选择金额或套餐及支付方式
       │
       ▼
  创建订单（PENDING）
  ├─ 校验金额区间、进行中订单数、每日限额
  ├─ 换算为网关币种（SePay 为 USD → VND）
  ├─ 负载均衡选择服务商实例
  └─ 调用服务商获取支付信息
       │
       ▼
  用户完成支付
  ├─ SePay        → VietQR 码 + 可复制的转账信息（银行、账号、
  │                 户名、金额、转账备注），页面轮询订单状态
  └─ NOWPayments  → 新窗口打开托管账单页 / 移动端跳转
       │
       ▼
  回调验证通过 → 订单 PAID → RECHARGING
       │
       ▼
  余额到账或订阅开通 → 订单 COMPLETED
```

### 订单状态说明

| 状态 | 说明 |
|------|------|
| `PENDING` | 等待用户支付 |
| `PAID` | 支付已确认，等待发放 |
| `RECHARGING` | 发放处理中 |
| `COMPLETED` | 余额已到账 / 订阅已开通 |
| `EXPIRED` | 超时未支付 |
| `CANCELLED` | 用户或管理员取消 |
| `FAILED` | 发放失败，管理员可在订单列表重试 |

> 本系统不包含退款流程：银行转账与加密货币均无自动退款接口。线下退回的款项请在自有账目中处理。

### 超时与对账

- 后台任务每 **60 秒**执行一次；多实例部署下通过 leader 锁保证同一周期只有一个节点执行。
- 判定过期前会先查询上游支付状态，避免把「刚付完但 webhook 还没到」的订单错误过期。
- 结算页在等待过程中也会请求服务端重新核验待支付订单——对 SePay 而言，只有配置了**用户 API Token** 时该核验才会真正查询银行流水。

## 从旧版本升级

SePay/NOWPayments 迁移之前的版本内置的是 EasyPay、支付宝、微信支付、Stripe、Airwallex。该迁移会：

- **停用**（而非删除）已下线服务商的实例——历史订单仍引用它们，保留记录可以查看旧订单的收款商户。这些实例无法再启用：管理界面不再提供这些 key，服务商工厂也会拒绝创建。
- **移除退款子系统**：退款相关字段被删除，处于退款状态的订单统一改为 `CANCELLED`。
- **清空启用支付类型列表**，避免结算页继续展示无法解析到服务商的方式，请重新勾选需要的方式。
- **删除旧的 USD → CNY 订阅汇率**。替代的汇率换算目标是 **VND**，必须重新设置——沿用旧数值会少收约四个数量级。

升级后请：添加 SePay 和/或 NOWPayments 实例，使用 SePay 时设置 USD → VND 汇率，重新启用支付方式，并登记新的 webhook 地址。
