# 2026-11-13 上游更新与 v0.2.27 发布说明

本次合入 `Wei-Shaw/sub2api` 默认分支的 83 个新增提交，更新至 `530c5e3a4f9c73ca2b0881191d0ef8e0d82c5484`。采用合并提交保留双方完整历史，合并前的 69 个本地独有提交继续保留。个人仓库版本从 `0.2.26` 升为 `0.2.27`。

## 用户可感知的更新

- 账号刷新时保留现有列表和额度展示；Antigravity 支持主动刷新用量。
- API 密钥列表与用量统计分别加载，减少等待，并新增用量查询覆盖索引。
- 充值倍率支持最多六位小数；易支付可按网关配置退款成功码；系统设置保存按钮改为底部吸附显示。
- 合入 Claude Fable、Mythos 5.2 支持及计费数据更新，完善 Sonnet 5.5 缓存读取计费。
- OpenAI 缓存写入支持区分 30 分钟和 12 小时用量及定价，管理页同步展示。
- 合入登录刷新令牌原子轮换、调度槽释放、Codex 页面上下文、WebSocket、图片错误状态、推理参数、模型冷却策略和审计任务唤醒等修复。

## 本地功能保留与冲突处理

- 保留个人仓库的更新、下载和回退来源，以及有更新提示时的回退入口。
- 保留账号订阅档位筛选、ChatGPT 活动会话管理、勾选退出其他会话、数量显示及当前会话保护。
- 保留充值金额的最低与最高范围筛选、充值和订阅页面布局、续费流程。
- 保留模型白名单和映射的统一 JSON 编辑、默认 Skills、自定义计费单位、订阅用量展示、代理快照等本地配置与业务。
- 充值页保留本地订单摘要布局，并使用上游新的倍率格式化方法显示六位小数。
- 用量记录同时保存上游的两项缓存时长字段和本地代理快照；同步处理单条写入、批量写入、查询扫描、参数类型及占位符顺序。
- 按合并后的 Ent schema 重新生成数据库代码，校正字段索引；已有测试文件仅处理合并及对应字段偏移，不自行新增测试。
- 版本文件使用个人仓库的 `0.2.27`，避免被上游 `0.2.21` 覆盖。

以共同祖先 `6b4b37db43443b5e88e424fe3c69602cc3810dfb` 为基准，157 个仅本地改动的文件与合并前一致，157 个仅上游改动的文件与上游一致。双方共同改动 45 个文件，已审查交叉修改；其中 10 个文件的文本冲突已处理。

## 数据库变更

新增上游原始迁移 `249_add_usage_logs_api_key_cost_index_notx.sql` 和 `250_openai_cache_write_ttl.sql`，分别添加 API 密钥用量查询覆盖索引、缓存写入时长字段及相关定价字段。本地已有迁移保持原样。迁移按完整文件名记录执行状态，同数字前缀的不同迁移可并存。

保留上游迁移的原始内容与校验和，包括原有文件末尾空行。本次没有连接线上数据库或执行迁移；应用升级启动时沿用项目现有迁移机制。
