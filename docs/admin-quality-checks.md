# 账号回答检查与票据管理

管理员侧边栏的「降智检查」使用两道固定题观察各 OpenAI 账号的回答：小鹅骑自行车 SVG，以及允许通过手感区分形状的糖果推理题。可手动检查单个账号或全部账号，也可开启每 10 分钟的后台检查。新安装默认关闭自动检查。

## 执行与结果

- 请求按账号 ID 定向发送，不使用网关选号。两题串行执行，最多同时检查 4 个账号，每题超时 150 秒；检查会消耗对应账号额度。
- PostgreSQL 保存调度时间、运行租约和最近 36 轮结果，浏览器关闭后继续执行。自动调度与手动触发共用租约，避免同一账号重复检查。
- 自定义题目实际写入 Responses 请求体，检查不提供联网工具。
- SVG 以隔离的图片缩略图显示，点击放大；原文可展开。结构有效仅显示「待目测」，不自动认定绘图质量。
- 糖果题按固定摸取数量的保证值为 29 颗：最多可以取到 28 颗而仍缺少一组交叉口味/形状组合。自动检查只核对答案数值，推导仍需人工复核。调用错误、缺票和回答不一致分别显示，不能仅凭这两题认定模型降级。

## 票据同步

每题发出前复用普通请求的 Codex 票据选择逻辑，按当前账号和最终出站模型读取较新的有效票据。启用票据且模型在管理范围内时，缺票或过期的检查不会降级为无票调用，而是记录「等待有效票据」，在后续检查重新读取。

结果保存该次注入的账号、模型、长度、获取时间和有效期，不保存或返回票据原文。历史记录显示当时的状态，不会随后台刷新被改写；旧结果未记录注入信息时会明确标注。

「292 打票」页面提供运行设置、账号票据状态、代理池导入/清空与 OnesProxy API 配置。代理池失败淘汰、状态统计及可选自动补充不改变业务请求所用的账号代理。服务端校验提取链接，禁止重定向携带密钥；管理 API 不返回已保存的代理服务令牌。

代理池与服务商配置存放于 `/app/data/ticket-proxy-pool.json` 和 `/app/data/ticket-proxy-provider.json`，需要持久化该目录。API 凭据应通过管理页面配置，源码和示例不包含可用凭据。

## 服务器流量条幅

条幅仅对管理员显示，每 2 秒刷新；页面隐藏时暂停轮询。它展示指定宿主机网卡的上传/下载速率、最近 5 分钟曲线和网卡累计流量，不能当作应用账单或单用户流量。

容器部署需只读挂载要观察的接口计数器。例如在 Sub2API 服务的 `volumes` 中添加：

```yaml
- /sys/class/net/eth0/statistics:/host-network/eth0:ro
```

将 `eth0` 替换为实际公网接口。无需挂载 Docker socket；未配置或读取失败时显示不可用，不回退到包含数据库通信的容器接口。

## 数据迁移

`232_account_quality_checks.sql` 新增配置、调度和检查结果表。它使用独立文件名，可与同号的其他既有迁移并存。已有账号、API Key 与使用记录无需变更。
