# Sub2API 前端 yui.web 黑白灰视觉重设计结果

## 修改范围

- 前端默认品牌显示改为「天才程序员小站」，默认副标题为 `AI API Gateway`。
- Tailwind token、全局组件基线、布局壳、首页、认证页、用户页、管理后台、支付、图表和新手引导已灰阶化。
- 常驻订阅进度、近期用量、平台/模型/计费标签改为黑白灰体系；错误和破坏性状态保留红色，风险阈值保留橙/红提醒。
- 后端、API、数据库、路由和计费逻辑未修改。

## 验证结果

- `pnpm vitest run ...`：目标测试集合通过。
- `pnpm build`：通过。
- 浏览器代表页：`/`、`/login`、`/dashboard`、`/keys`、`/purchase`、`/admin/dashboard`、`/admin/users`、`/admin/accounts`、`/admin/settings` 已用本地 dev server 和临时 mock 后端检查。
- 浅色模式：页面背景为白/浅灰，正文为深灰/黑，默认品牌显示「天才程序员小站」，未发现青绿色、蓝紫色主视觉残留。
- 深色模式：页面背景为黑/深灰，正文为浅灰/白，默认品牌显示「天才程序员小站」，未发现青绿色、蓝紫色主视觉残留。

## 已知取舍

- 错误状态、删除/退出等破坏性动作保留红色。
- 用量接近限制时保留橙/红风险提示。
- 支付二维码和支付服务商标识保留最低品牌识别度。
- 字体使用 Google Fonts，保留系统字体回退。
