# 仪表盘移除模型拆分卡片设计与计划

## 背景

- 用户要求：仪表盘页面中删除「按模型拆分」部分的卡片组件，其他不变。
- 截图对应用户仪表盘 `/dashboard` 下方左侧「模型分布」卡片。
- 当前实现位于 `frontend/src/components/user/dashboard/UserDashboardCharts.vue`，该组件同时包含时间范围筛选、刷新、粒度选择、「模型分布」卡片和「Token 使用趋势」卡片。

## 方案取舍

推荐方案：直接从 `UserDashboardCharts.vue` 移除「模型分布」卡片及其 Doughnut 图表依赖，保留时间范围筛选、刷新、粒度选择和「Token 使用趋势」卡片。

不采用只隐藏方案，因为会留下无用渲染逻辑和图表依赖。暂不删除 `DashboardView.vue` 里的模型统计接口调用，因为本次需求只要求删除卡片，移除接口会扩大数据流影响面。

## 实现计划

1. 新增组件测试，挂载 `UserDashboardCharts.vue` 时断言：
   - 不再渲染「模型分布」文案和模型表格内容。
   - 仍渲染「Token 使用趋势」和筛选区域。
2. 先运行该测试，确认它因现有「模型分布」卡片仍存在而失败。
3. 修改 `UserDashboardCharts.vue`：
   - 删除「模型分布」卡片模板。
   - 删除 `Doughnut`、`computed`、格式化函数、灰阶图表调色板和 `ArcElement` 等仅服务模型卡片的依赖。
   - 将图表区域从双列改为单列，让「Token 使用趋势」自然占满宽度。
4. 运行目标测试、前端类型检查和构建。
5. 新增结果文档，并在 `AGENTS.md` 追加运行记录。

## 风险

- 风险主要在误删 Token 趋势图依赖。测试会覆盖趋势卡片仍存在，类型检查会覆盖 import 和 props 问题。
- 本次不改后端、计费、API、路由、订阅、兑换码和公网配置。
