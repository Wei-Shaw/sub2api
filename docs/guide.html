Codex CLI

Codex CLI 是 OpenAI 的命令行编码助手，支持 GPT-5.5 等最新模型。

配置环境变量

Terminal
# 设置 API 地址和密钥
export OPENAI_BASE_URL="https://api.kaiaigo.com/v1"
export OPENAI_API_KEY="sk-your-key"

# 使用 GPT-5.5
codex --model gpt-5.5

Terminal

Cursor

Cursor 是 AI 驱动的代码编辑器，支持自定义 API 端点。

配置步骤

  1. 打开 Settings → Models → OpenAI API Key，输入你的 API Key
  2. 在 Override OpenAI Base URL 中输入以下地址
  3. 保存设置，开始新对话即可使用
Override OpenAI Base URL
https://api.kaiaigo.com/v1

OpenAI SDK

适用于 Python / Node.js 项目中直接调用 OpenAI 兼容 API。

Python

Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://api.kaiaigo.com/v1"
)

response = client.responses.create(
    model="gpt-5.4-mini",
    input="Hello!"
)
print(response.output_text)

Node.js

JavaScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-your-key",
  baseURL: "https://api.kaiaigo.com/v1",
});

const response = await client.responses.create({
  model: "gpt-5.4-mini",
  input: "Hello!",
});
console.log(response.output_text);

状态码含义解决方案

常见问题

支持哪些模型？

目前支持 OpenAI Codex 系列模型（gpt-5.x），包括 gpt-5.5、gpt-5.4、gpt-5.4-mini、gpt-5.3-codex、gpt-5.2 和 gpt-image-2。

API Key 怎么获取？

打开 API Keys 页面创建或查看你的 API Key。

支持 Claude / Gemini 吗？

暂不支持。本站专注于 OpenAI Codex 系列模型。

请求报 503 怎么办？

503 表示当前没有可用的上游账号。可能是所有账号都在限流冷却中，请等待 1-2 分钟后重试。

Base URL 要加 /v1 吗？

OpenAI 兼容接口需要加 /v1。Codex CLI 的 OPENAI_BASE_URL 也需要包含 /v1。
