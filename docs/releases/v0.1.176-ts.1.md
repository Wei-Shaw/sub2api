# TokenSupply v0.1.176-ts.1

## Highlights

- 追上上游 `v0.1.176`，新增分组级逐模型定价与长上下文阶梯开关，并同步 Grok 4.6/JWT 档位、x_search、Realtime 音频计费和备份 leader 锁等上游改进。
- 修复 API Key 认证缓存命中时可能丢失分组模型价格与长上下文开关的问题，避免请求退回错误定价。
- 分组定价迁移专门按蓝绿部署和回滚场景加固，旧容器与新容器共存时保持原有默认行为。

## Fork Changes

- API Key 认证缓存快照升级为 v20，完整保存 `LongContextPricingEnabled` 和 `ModelPricing`；已存在的 v19 快照会自动淘汰并回源重建。
- 数据库持久失效触发器同步覆盖上述两个 v20 字段；即使直接改 SQL，或应用在提交后、主动清缓存前意外退出，也不会继续沿用旧定价快照。
- 新增 Redis JSON 往返和定价解析回归测试，覆盖模型通配符、价格字段、intervals、长上下文开关与旧快照拒绝。
- 迁移 234 使用可空、无数据库默认的扩展列，通过 PostgreSQL 触发器为旧版写入恢复历史默认值，同时尊重新版显式关闭。
- managed-update 迁移门禁新增对 `CREATE OR REPLACE TRIGGER` 的精确识别，且仍必须带 `reviewed-compatible` 人工审阅标记，不会放宽其他未知 `CREATE` 语句。

## Upstream Changes

- Baseline: `upstream/v0.1.175` -> `upstream/v0.1.176`。
- 分组可为具体模型设置定价，并可单独控制长上下文阶梯计价。
- Grok 增加 4.6 目录、JWT 订阅档位识别、用量展示和容量故障改进。
- OpenAI/Grok 增加原生 `x_search` 路径和搜索来源传递；Realtime 音频计费仅在真正观察到音频时生效。
- 定时备份增加 leader 锁，避免蓝绿或多实例环境重复执行。

## Configuration And Migrations

- 新增 `backend/migrations/234_group_model_pricing.sql`，添加 `groups.long_context_pricing_enabled` 和 `groups.model_pricing`；迁移 235 将这两列纳入认证缓存的持久失效触发器。
- 存量分组与旧版容器的默认行为为开启长上下文计价；新版显式设为关闭时不会被触发器覆盖。
- 不新增必须配置的环境变量。

## Deployment And Rollback

- 使用现有 deployer 蓝绿更新即可，不需要停机维护。
- 迁移列保持可空且无数据库默认；触发器保护旧 writer 的历史行为，因此可在蓝绿共存期间回滚到上一个已完成的 fork 版本。
- 正式 tag 只能由 `Promote Release` workflow 在精确 `main` SHA 通过所有门禁后创建，不手工创建或覆盖。

## Known Limitations

- v19 Redis 认证快照第一次命中时会被拒绝并增加一次数据库回源，这是为确保正确计费的一次性成本。
- 迁移 234 暂时依赖数据库触发器维持旧容器兼容；等旧版回滚窗口彻底关闭后，可在后续版本收紧为 `NOT NULL`，当前不影响安全更新。
