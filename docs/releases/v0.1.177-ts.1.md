# TokenSupply v0.1.177-ts.1

## Highlights

- 追上上游 `v0.1.177`，补齐 Codex 回合状态回传、压缩探测和分组用量按日汇总。
- 提示词审计新增关键词拦截、OpenAI Moderation / Nemotron 节点、管理端代理，以及异步命中后的哈希预拦截。
- 渠道监控 v2 增加用户排行开关；全同步无流式时首字 `-` 不再标红；7 天/30 天窗口改读仍在更新的小时汇总，避免整页变灰。
- 色块矩阵不再用滚轮放大，避免抢走页面滚动。
- Codex 指纹收敛改为显式开启，未配置的账号保持原来的客户端身份。

## Fork Changes

- 提示词审计支持三种策略：仅 AI、仅关键词、关键词 + AI；关键词同步阻止和 AI 同步阻止可分开开关。
- 审计节点除 Qwen3Guard 外，可接入 OpenAI Moderation 和 Nemotron 3.5 Content Safety，并可走后台已配置的代理。
- 异步 AI 审计命中 Block 后，只把提示词的 SHA-256 记入 Redis；后续相同内容可在发出请求前直接拦截。后台支持删除或清空这些哈希。
- 旧的提示词审计配置没有新字段时，仍按原来的「仅 AI」理解，并把旧的同步开关映射到两个新开关。
- 本版本不含对方 fork 的「提示词审计拦截后换分组」。
- 渠道监控 v2 增加「用户排行」开关，可对普通用户隐藏排行页。
- 全是同步、没有流式时，首字时延显示 `-`，不再当成红色异常。
- 7 天/30 天监控改为从仍在更新的 1 小时汇总拼出 12 小时/1 天柱，不再读已经停更的粗粒度表。
- 色块矩阵去掉滚轮缩放和重置按钮，色块区滚轮只滚动页面。
- 尚未发版的迁移 236/237/238 改成可回滚镜像的写法，并把关键词索引挪到并发创建的 239。

## Upstream Changes

- Baseline: `upstream/v0.1.176` -> `upstream/v0.1.177`。
- Codex 转发 `x-codex-turn-state`，并阻止跨账号回声；指纹收敛改为 opt-in。
- Codex 压缩区分 native / legacy 路由，补 session-level beta features，并探测 native compaction v2。
- 分组用量新增按日汇总和时区跟踪，后台启动时回填；管理端用量摘要改走服务端时区，并增加昨日费用。
- Grok 长上下文只跟分组开关，不受 OpenAI 账号开关否决；未知文本模型兜底排除 image/video/audio。
- Go 工具链：`1.26.5` → `1.26.6`。

## Configuration And Migrations

- 新增 `backend/migrations/236_group_usage_daily_rollups.sql`、`237_group_usage_rollup_timezone.sql`：分组用量日汇总表和时区列。时区列可空，旧写入由迁移补默认值。
- 新增 `backend/migrations/238_prompt_audit_keywords.sql`：给提示词审计事件增加可空 `matched_keyword` 列，并用触发器把旧写入补成空字符串。
- 新增 `backend/migrations/239_prompt_audit_keywords_index_notx.sql`：并发创建关键词索引，避免管理更新时堵表。
- 提示词审计配置仍写在现有 `prompt_audit_config` 设置项中，不新增必须配置的环境变量。
- 渠道监控 v2 的用户排行开关写在现有监控配置里，默认保持原样。
- 哈希黑名单只存在 Redis，不进数据库；重启或清空 Redis 后需要重新积累。

## Deployment And Rollback

- 使用现有 deployer 蓝绿更新即可，不需要停机维护。
- 先跑迁移 236/237/238/239，再滚动新镜像。
- 新表/新列可空或仅新版本使用；应用可回滚到上一完成版本 `v0.1.176-ts.1`。
- 回滚后分组用量日汇总和关键词/哈希审计会停止更新，不影响既有计费流水。
- 回滚后 7 天/30 天监控会回到旧读路径，页面可能再次变灰；色块滚轮缩放也会回来。
- 正式 tag 只能由 `Promote Release` workflow 在精确 `main` SHA 通过所有门禁并完成最终独立审计后创建，不手工创建或覆盖。

## Known Limitations

- 启动时分组用量回填没有纳入 dashboard 停机等待；滚动发布可能中断回填，最多占独立锁约 31 分钟，只影响汇总补齐速度，不改计费流水。
- `/admin/groups/usage-summary` 不再使用浏览器时区，改走服务端时区，并新增 `yesterday_cost`。
- 提示词审计按筛选删除时，若其他事务锁住中间行，cursor 可能漏删；不是审计绕过。
- 打开哈希预检后，即使两个同步开关都关，第二次相同提示词也会在发请求前被拦住。
- 渠道档位快照与 Grok 长上下文门闩的组合单测尚未补齐；两边各自有测试。
- Codex 指纹收敛默认关闭，是上游的破坏性变化；已显式选过档位的账号不变。
- 渠道监控 7 天/30 天不再回填已经停更的 12 小时/1 天表；只改读路径。监控页模型名仍显示原始请求模型，未自动改用渠道定价模型。
- 折线图仍可用滚轮缩放；只有色块矩阵去掉了滚轮放大。
- 迁移 238 第一次应用到已有大量审计事件的库时，会在同一事务里更新空关键词行。
