# TokenSupply v0.1.177-ts.2

## Highlights

- 修复 `0.1.177-ts.1` 上线后 7 天/30 天监控仍全灰：切桶起点与页面格子差了 8 小时。
- 渠道监控页去掉折线图、筛选和模型/错误表，只保留时间范围、综合色块，以及可选的用户排行。
- 图片工作台顶栏描述缩短，右边文档不再被挤成两行。

## Fork Changes

- 7 天/30 天 `date_bin` 起点钉死为 UTC `1970-01-01 00:00:00+00`，与 `ParseFilter` 和前端色块对齐。数据库会话时区不是 UTC 时也不会再错位。
- 监控页删除折线图和脉冲/折线切换；健康度固定综合；平台/分组/模型筛选删除，始终看全部；维度固定平台/分组。
- 下方模型表和错误原因表删除。用户排行开关打开时仍显示排行。
- 图片工作台顶栏描述改短，标题区过长会截断，右侧操作保持单行。

## Upstream Changes

- Baseline: `upstream/v0.1.177`，与 `v0.1.177-ts.1` 相同。
- 本版本没有新的上游同步。

## Deployment And Rollback

- 使用现有 deployer 蓝绿更新即可，不需要停机维护。
- 无新迁移。
- 应用可回滚到上一完成版本 `v0.1.177-ts.1`。
- 回滚后 7 天/30 天在非 UTC 数据库时区下会再次全灰；监控页折线图/筛选/明细表和图片工作台长描述也会回来。
- 正式 tag 只能由 `Promote Release` workflow 在精确 `main` SHA 通过所有门禁并完成最终独立审计后创建，不手工创建或覆盖。

- 渠道监控 7 天/30 天仍不回填已经停更的 12 小时/1 天表；只改读路径和切桶对齐。
- 监控页模型名仍显示原始请求模型，未自动改用渠道定价模型。
- 色块按 UTC 12 小时/1 天网格对齐，与北京时间整点不必重合。
