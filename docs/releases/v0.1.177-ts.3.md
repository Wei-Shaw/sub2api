# TokenSupply v0.1.177-ts.3

## Highlights

- Google AI Pro/Ultra 的 Antigravity 账号不再默认打到生产端点被 429 挡掉，会自动走官方客户端同款 daily 端点。
- 接上上游对 Kimi / 智谱 / DeepSeek 的一等支持和渠道分时定价，不必再手动改环境变量才能用付费 Antigravity。

## Fork Changes

- Antigravity 未设置 `GATEWAY_ANTIGRAVITY_FORWARD_BASE_URL` 时，`plan_type` 为 Pro/Ultra 的账号默认转发到 daily；免费和未识别套餐仍走生产端点，避免再出现 daily 401。
- 环境变量覆盖仍然优先。老账号如果还没有 `plan_type`，行为和以前一样，可重新授权或手动设环境变量。

## Upstream Changes

- Baseline: `upstream/v0.1.177` -> `upstream/8869775ed`（上游尚未打新版本 tag，VERSION 仍为 `0.1.177`）。
- 新增 Kimi / Zhipu / DeepSeek 国产供应商账号、配额和余额监控，并允许创建对应平台分组。
- 渠道模型支持分时倍率定价。
- Codex 收敛 identity，并回填缺失的 fingerprint seed。
- Grok 响应模型审计别名规范化。
- 构建镜像 Go 版本与 `go.mod` 对齐到 1.26.6。
- OpenAI Fast/Flex 策略说明和若干后台 i18n/图例修复。

## Configuration And Migrations

- 沿用现有 `GATEWAY_ANTIGRAVITY_FORWARD_BASE_URL`，无新增环境变量。
- 新增迁移：
  - `240_user_platform_quotas_add_cn_providers.sql`：配额平台 CHECK 加入 kimi/zhipu/deepseek。
  - `241_backfill_codex_fingerprint_seed.sql`：给启用 fingerprint 的 OpenAI OAuth 账号回填 seed。
  - `242_channel_model_time_pricing.sql`：渠道定价增加可空 `time_pricing` 列。
- 三条迁移都可重放；旧镜像在蓝绿期间仍可读写。

## Deployment And Rollback

- 使用现有 deployer 蓝绿更新即可，不需要停机维护。
- 应用可回滚到上一完成版本 `v0.1.177-ts.2`。
- 回滚后付费 Antigravity 账号会再次默认走生产端点；国产供应商入口、分时定价和 fingerprint 回填对旧镜像不可用。
- 正式 tag 只能由 `Promote Release` workflow 在精确 `main` SHA 通过所有门禁并完成最终独立审计后创建，不手工创建或覆盖。

## Known Limitations

- 没有 `plan_type` 的付费 Antigravity 老账号仍会走生产端点并可能 429，需要重新授权或设置环境变量。
- 上游尚未发布新版本号，本 fork 修订仍挂在 `0.1.177` 基线上。
- 渠道监控既有限制不变：7 天/30 天不回填停更的 12 小时/1 天表；色块按 UTC 网格对齐。
