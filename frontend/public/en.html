How cheap is the Claude API here vs. direct?

Does it work with Claude Code?

Yes. Set ANTHROPIC_BASE_URL to our gateway and use your issued API key. Sticky sessions keep long Claude Code conversations coherent.

Is it OpenAI-compatible for ChatGPT?

Yes. Drop-in replacement for api.openai.com — change the base URL, keep your existing code.

How does billing work?

Prepaid tokens. Every request debits your balance based on input + output tokens. Full per-request logs available.

Do you support Gemini and Claude Code together?

Yes — one account, one key, access Claude Opus/Sonnet, Claude Code, GPT-4o, and Gemini 2.0 through the same endpoint.
