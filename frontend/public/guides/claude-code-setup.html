Claude Code 接入中转 API 教程

Claude Code 官方订阅按月收费，高频使用时账单不小。把 ANTHROPIC_BASE_URL 指向 Token之家，按实际 token 计费，通常省 50% 以上， Sonnet 4 / Opus / Haiku 都能用。全程 5 分钟。

核心就两行： ANTHROPIC_BASE_URL=https://tokenzhijia.shop + ANTHROPIC_API_KEY=你在后台创建的密钥。下面是每一步的细节。

开始之前

  • Node.js ≥ 18（node -v 验证）
  • 一个 Token之家账号 和里面的 API 密钥
  • 终端权限可以写环境变量（macOS / Linux / Windows 都行）

一步步配置

  1. 安装 Claude Code

    官方 CLI，npm 全局安装：

    npm install -g @anthropic-ai/claude-code

    安装完成后 claude --version 应能看到版本号。

  2. 在 Token之家创建 API 密钥

    注册登录后进入「API 密钥」页，点「创建密钥」。 建议给每个项目单独一个密钥，方便用量追踪与快速吊销。

    密钥只显示一次。创建后立即复制保存。丢了只能重建。

  3. 设置环境变量

    两种做法，按你的偏好选。

    临时（当前 shell 有效）：

    # macOS / Linux
export ANTHROPIC_BASE_URL="https://tokenzhijia.shop"
export ANTHROPIC_API_KEY="你的 Token之家密钥"

# Windows PowerShell
$env:ANTHROPIC_BASE_URL = "https://tokenzhijia.shop"
$env:ANTHROPIC_API_KEY = "你的 Token之家密钥"

    永久（每次新终端都生效）：

    # 写入 shell 配置（根据你的 shell 选一个）
echo 'export ANTHROPIC_BASE_URL="https://tokenzhijia.shop"' >> ~/.zshrc
echo 'export ANTHROPIC_API_KEY="你的密钥"' >> ~/.zshrc
source ~/.zshrc

    bash 用户把 ~/.zshrc 换成 ~/.bashrc。

  4. 启动 Claude Code 验证

    进入任意项目目录运行：

    cd your-project
claude

    第一次启动会问你几个配置问题（模型偏好、工具权限），照默认走就行。 然后随便问一句「帮我看看这个项目结构」，如果回复正常，说明中转通了。

  5. 查看用量与账单

    回到 Token之家后台 → 用量，能看到每次 Claude Code 请求的：

    • 调用模型（Sonnet 4 / Opus / Haiku）
    • 输入 / 输出 token 数
    • 实际扣费
    • 时间戳与请求 ID

    余额低于阈值会邮件通知，避免突然停服。

常见报错与修复

报错信息原因修复
401 Unauthorized 密钥错误或未设置 检查 echo $ANTHROPIC_API_KEY 是否输出你的密钥
ENOTFOUND tokenzhijia.shop 网络不通或 DNS 解析失败 确认本地能 curl https://tokenzhijia.shop
429 Too Many Requests 短时间内请求过多 等待片刻或联系客服提额
402 Insufficient Balance 余额不足 后台充值，最低 $1
model not supported Claude Code 请求了中转未开放的模型 使用 claude config 切换到 Sonnet 4 / Opus / Haiku

进阶：多项目 / 多账号

每个项目想用独立密钥？在项目根目录创建 .env 或在 package.json 启动脚本里覆盖环境变量即可： 

# 项目 A 的 .env
ANTHROPIC_BASE_URL=https://tokenzhijia.shop
ANTHROPIC_API_KEY=sk-xxxxx-project-a

# 启动时
source .env && claude

后台也可以给同一个账号创建多个密钥，分别查账单。

为什么中转比官方便宜

Claude Code 官方订阅按月收费，无论用多少都是固定价。中转站把多个订阅账号的额度池化， 按你实际的 token 用量计费 —— 不用满的月份你不亏，用超的月份也不会被单账号限速。 详见 Claude Code 中转 vs 官方订阅。

常见问题

支持 Claude Code 的所有功能吗？

支持。Claude Code 的对话、工具调用、文件编辑、bash 执行都正常工作。MCP 服务器配置也不受影响。

粘性会话怎么处理？

同一个密钥的连续请求会尽量落到同一个上游账号，保持对话上下文缓存命中，省更多钱。

能和 Cursor、Cline 一起用吗？

能。同一把密钥可以同时被 Cursor、 Cline、Claude Code 共享使用。

企业用能否开发票？

可以。后台支持导出 CSV 账单，联系客服可出具发票。
