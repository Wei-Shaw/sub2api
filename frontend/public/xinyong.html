信任说明：计费、日志与合规

TokenProvider 是 第三方 API 网关（中转），并非 Anthropic、OpenAI 或 Google 官方产品。 本页用可引用的事实性语言说明计费单位与责任边界；与注册流程中的服务条款与隐私政策不一致时，以条款全文为准。

三句话：① 预购代币余额，按每次调用的输入/输出 token 扣费。② 请求经网关路由至上游官方 API 账号池。 ③ 具体日志字段、保存时长与法务文本以应用内公示为准。

计费单位

按 token 计量（由上游模型返回的用量统计汇总）。单价与最小充值以登录后的控制台展示为准， 并可能随上游官方调价而调整。本站不宣称与任何官方厂商存在隶属关系。

日志与数据

网关为实现计费、排错与安全风控，会处理必要的请求元数据；是否存储完整 prompt、保留多久等细节， 以应用内《隐私政策》为准。本营销页不构成合同承诺。

上游可用性

若上游出现限流、故障或政策变更，通过网关的调用同样可能失败；我们不保证与直连官方 API 完全相同的 SLA。

滥用与封号

违反条款的共享密钥、批量滥用或违法用途可能导致停用；细则见产品内条款。
