接入说明

Look2Eye 完全兼容 OpenAI API 格式。只需将 Base URL 替换为以下地址，即可使用所有支持的模型：

Base URL: https://api.look2eye.com

所有请求需要在 Header 中携带 API Key：

Authorization: Bearer sk-your-api-key

获取 API Key

登录后在控制面板中创建令牌即可获得 API Key。每个令牌可以独立设置额度和权限。

  1. 访问 控制面板 并登录
  2. 进入「令牌」页面
  3. 点击「新建令牌」
  4. 复制生成的 API Key（以 sk- 开头）

Claude Code 配置

macOS / Linux

在终端中设置环境变量：

export ANTHROPIC_BASE_URL=https://api.look2eye.com
export ANTHROPIC_API_KEY=sk-your-api-key

建议将以上内容添加到 ~/.bashrc 或 ~/.zshrc 中以持久化配置。

Windows

set ANTHROPIC_BASE_URL=https://api.look2eye.com
set ANTHROPIC_API_KEY=sk-your-api-key

Cursor 配置

打开 Cursor 设置，找到 Models 配置区域：

  1. 打开 Settings > Models
  2. 点击 "Override OpenAI Base URL"
  3. 填入 https://api.look2eye.com/v1
  4. 填入你的 API Key

Chatbox 配置

在 Chatbox 设置中选择 OpenAI API 提供商：

API Domain: https://api.look2eye.com
API Key: sk-your-api-key
Model: claude-sonnet-4-20250514

Cherry Studio 配置

在设置中添加自定义服务商：

服务商类型: OpenAI
API 地址: https://api.look2eye.com/v1
API Key: sk-your-api-key

OpenAI SDK 集成

Python

from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.look2eye.com/v1"
)

response = client.chat.completions.create(
    model="claude-sonnet-4-20250514",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)

Node.js

import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.look2eye.com/v1',
});

const response = await client.chat.completions.create({
  model: 'claude-sonnet-4-20250514',
  messages: [{ role: 'user', content: 'Hello!' }],
});
console.log(response.choices[0].message.content);

cURL 示例

curl https://api.look2eye.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {"role": "user", "content": "你好"}
    ],
    "stream": true
  }'
