## Why

外部工具目前缺少一个受用户身份约束的文件暂存入口，只能绕过平台直接写对象存储，也无法在管理后台独立吊销访问凭证。新增用户级开发者密钥与文件 API，可让外部工具安全上传临时文件，并在文件被加入素材库时完成服务端归档。

## What Changes

- 在右上角个人菜单的“企业管理”下方增加“开发者密钥”，通过弹窗创建、查看和删除当前用户的开发者密钥；密钥明文仅在创建成功时展示一次。
- 新增用户级开发者密钥数据与鉴权能力，凭证仅用于开发者文件 API，不复用模型计费 API Key 或全局内部 API App。
- 新增 `POST /api/v1/file/` 文件上传接口和 `DELETE /api/v1/file/` 文件删除接口，支持开发者密钥访问，并返回上传对象的公开访问 URL。
- 文件 API 上传的对象统一限制在 COS 配置 `prefix` 下的 `file_uploads` 暂存目录，并按用户隔离；删除只允许操作调用密钥所属用户上传的暂存对象。
- 修改 `AddMaterialByUrl`：当 URL 指向当前 COS 的 `file_uploads` 暂存对象时，使用对象存储服务端移动能力迁移到用户素材目录，再保存迁移后的 URL 和对象键；非暂存 COS URL 继续沿用既有登记行为。
- 调整用户素材库列表的卡片密度，支持点击图片查看自适应大图，并允许登录用户修改自己素材的展示文件名；重命名不改变 COS 对象 key 或访问 URL。

## Capabilities

### New Capabilities
- `developer-key-management`: 当前登录用户创建、列出和删除仅用于开发者 API 的独立密钥。
- `developer-file-api`: 使用开发者密钥上传和删除用户隔离的 COS 暂存文件，并取得公开 URL。

### Modified Capabilities
- `console-navigation`: 在已认证控制台的个人菜单中增加开发者密钥入口和管理弹窗。
- `media-cos-archival`: 将文件 API 暂存 URL 添加为素材时，把 COS 对象移动到该用户的素材目录并登记新地址。
- `material-library`: 使用自适应素材卡片，提供图片大图预览和用户归属隔离的展示名称修改能力。

## Impact

- 后端：数据库迁移、Ent schema/生成代码、开发者密钥 repository/service/handler、中间件与路由、COS 对象移动、素材服务及用户素材改名端点。
- 前端：个人菜单、开发者密钥 API 客户端、管理弹窗、紧凑素材卡片、素材改名交互、国际化和组件测试。
- API：新增登录态下的开发者密钥管理端点、Bearer 开发者密钥鉴权的 `/api/v1/file/` 端点，以及登录用户的素材改名端点。
- 安全：数据库只保存密钥摘要与显示前缀；上传/删除和素材迁移均校验用户归属及 COS key 目录边界。
