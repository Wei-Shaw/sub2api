## ADDED Requirements

### Requirement: 个人菜单提供开发者密钥管理入口
已认证控制台顶部个人菜单 SHALL 在“企业管理”条目之后显示“开发者密钥”命令。激活该命令 MUST 关闭个人菜单并打开开发者密钥管理弹窗，而不离开当前路由。

#### Scenario: 从个人菜单打开弹窗
- **WHEN** 用户点击“开发者密钥”
- **THEN** 个人菜单 SHALL 关闭，当前页面路由 SHALL 保持不变，开发者密钥管理弹窗 SHALL 打开并加载当前用户的密钥

#### Scenario: 没有企业管理权限仍可访问
- **WHEN** 普通用户的个人菜单不显示“企业管理”
- **THEN** “开发者密钥”命令 SHALL 仍然显示在 API 密钥条目之后的对应位置

### Requirement: 开发者密钥弹窗支持完整管理流程
开发者密钥弹窗 SHALL 支持输入名称创建密钥、一次性展示和复制新密钥、列出现有密钥，以及经确认后删除密钥。加载、提交、空列表和错误状态 MUST 有明确界面反馈。

#### Scenario: 创建并一次性展示密钥
- **WHEN** 用户在弹窗提交有效名称且创建成功
- **THEN** 弹窗 SHALL 展示完整新密钥和复制命令，并明确该值关闭后无法再次查看

#### Scenario: 删除密钥
- **WHEN** 用户确认删除列表中的密钥
- **THEN** 弹窗 SHALL 调用删除 API 并从列表移除该密钥

#### Scenario: 键盘和窄屏可用
- **WHEN** 用户通过键盘操作或在移动端打开弹窗
- **THEN** 所有输入、创建、复制、删除和关闭控件 SHALL 可访问且内容不得溢出视口
