## ADDED Requirements

### Requirement: 用户管理独立开发者密钥
系统 SHALL 允许已登录用户创建、列出和删除仅属于自己的开发者密钥。开发者密钥 MUST 与模型 API Key 和内部 API App 隔离，且不得用于访问文件 API 之外的接口。

#### Scenario: 创建开发者密钥
- **WHEN** 已登录用户提交有效的密钥名称
- **THEN** 系统 SHALL 创建归属于该用户的开发者密钥并返回一次性明文

#### Scenario: 列出开发者密钥
- **WHEN** 已登录用户打开开发者密钥管理弹窗
- **THEN** 系统 SHALL 只返回该用户的密钥名称、显示前缀、创建时间和最近使用时间，且 MUST NOT 返回密钥明文或摘要

#### Scenario: 删除开发者密钥
- **WHEN** 用户删除自己的一枚开发者密钥
- **THEN** 系统 SHALL 吊销该密钥，后续使用该密钥的文件 API 请求 SHALL 鉴权失败

#### Scenario: 隔离其他用户密钥
- **WHEN** 用户尝试删除不属于自己的开发者密钥
- **THEN** 系统 SHALL 返回未找到且不得泄漏该密钥是否存在

### Requirement: 开发者密钥安全存储
系统 MUST 使用加密安全随机数生成开发者密钥，并且数据库 SHALL 只保存不可逆摘要与可安全展示的短前缀。明文密钥 MUST 只在创建成功响应中出现一次。

#### Scenario: 创建后无法再次读取明文
- **WHEN** 用户关闭创建成功提示后重新打开密钥列表
- **THEN** 系统 SHALL 只展示密钥短前缀，无法再次取得完整密钥

#### Scenario: 数据库记录不含明文
- **WHEN** 系统持久化新开发者密钥
- **THEN** 持久化记录 SHALL 包含密钥摘要而非完整明文
