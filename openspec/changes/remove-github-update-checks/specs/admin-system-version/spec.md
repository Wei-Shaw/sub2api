## ADDED Requirements

### Requirement: 管理端版本徽标只展示当前构建版本
系统 SHALL 在管理端展示当前运行实例的构建版本，且该展示不依赖任何远端版本检测结果。

#### Scenario: 管理员查看侧边栏版本徽标
- **WHEN** 管理员打开管理端界面
- **THEN** 系统显示当前构建版本号
- **AND** 不显示远端更新提示点、最新版本号或在线更新入口

### Requirement: 系统版本接口只返回本地构建信息
系统 SHALL 提供一个只读版本接口，用于返回当前运行实例的构建版本，并且该接口不触发 GitHub Release 或其他远端更新源查询。

#### Scenario: 前端请求系统版本
- **WHEN** 前端请求系统版本接口
- **THEN** 系统返回当前构建版本
- **AND** 返回过程不依赖远端更新检查

### Requirement: 系统不得暴露 GitHub 驱动的在线更新能力
系统 SHALL 不再暴露基于 GitHub Release 的更新检查、在线更新或回滚入口。

#### Scenario: 客户端访问旧更新入口
- **WHEN** 客户端访问历史上的更新检查、在线更新或回滚入口
- **THEN** 系统不提供这些能力
