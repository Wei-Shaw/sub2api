# 倍率自动改名

源码基线取自线上 monitor.py，SHA256：
`9ec806a0d9e1d281fb67c29c61fcd3e9f5644f56f4bb3bad55d0a6011a5b9ec4`。

只替换明确的 `名称-倍率` 后缀，不自动追加倍率。
紧贴名称的数字、模型版本号和没有后缀的名称保持不变。
仍要求账号授权定价、单一有效倍率，并保留既有连续观察/倍率变化确认逻辑。
不修改优先级、分组、成本同步或通知规则，不自动恢复历史误改名称。

验证：`python3 -m unittest -q`。线上回放只能调用纯函数
`plan_account_renames`，不要用 `run_once` 代替无写入验证。
发布采用单实例交接，原容器停止后才启动新容器，避免两个任务同时修改账号。
镜像仅覆盖 monitor.py，继承当前已安装依赖；部署保留环境、挂载和网络。
