# BUAGA v0.2.7 升级候选

## 来源与范围

- 定制起点：`production` 的 `ace88a199`（`rel/buaga-openai-default-test-model-20260919`）。
- 上游：`Wei-Shaw/sub2api` 正式版 `v0.2.7`，提交 `aea725f2ea644d5592d0bbb1d63b607efa7e200a`。
- GitHub 标签对象：`7484192016807acf55c6ef4f2827d371eb61ec1c`；已通过 GitHub API 核对。
- 将 `v0.2.5..v0.2.7` 的增量合入权威定制仓库；没有使用官方镜像或历史源码副本覆盖定制版本。
- 本记录仅代表候选源码，未部署、未蓝绿切换。线上实际版本以服务器 `buaga-current.json` 为准。

## 主要变化

- 火山方舟 Seedance 原生任务接口，与 BUAGA 现有 OpenAI 兼容视频任务隔离。
- 插件宿主 KV、受权限约束的账号目录和只读状态通道。
- Antigravity Gemini 模型名与流兼容、Kimi Coding Plan 配额冷却、Codex 工具 schema、DeepSeek reasoning 回退修复。
- 移动端模型广场入口与上游表单修复，保留 BUAGA 桌面导航和界面。
- 保留现有通知、排序、定价、调度监控、图片/视频预览、工作台推荐及历史修复。

## 合并和回归修正

- Seedance 查询/删除不要求创建请求的 JSON；仅创建时记录待结算快照。
- OpenAI 兼容视频的持久化所有权校验仍保留；不可用时返回 503，不回退到 Seedance 的绑定。
- 真实显式 5xx 流错误继续换号；无状态码的临时通知不因默认 502 推断而立即中断后续完成事件。
- 参数/内容政策拒绝即使被上游包在 503 中，也不进入账号故障冷却。
- 修复流测试的管道阻塞，图片预览测试统一使用临时目录，不写生产媒体路径。
- 源码版本标识更新为 `0.2.7`；C-001 同步更新，新增 C-391～C-392 行为保护锚点。
