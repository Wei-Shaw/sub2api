# 视频任务记录补齐（候选，尚未切换主站）

问题：Grok/Ark 原生接口已经生成视频并写入使用记录，但视频任务列表只读取 OpenAI 持久化任务，原生任务不可见。

修复覆盖共享视频处理器的创建、编辑、延长、查询和下载，以及 Ark 原生任务入口。客户端创建接口继续使用 `POST /v1/videos`；未将视频请求改走 Responses/Chat。

- 向上游提交前写入任务表，归属固定为当次用户、密钥、分组、账号。
- 收到任务 ID 后关联原记录，再发送成功响应。上游错误或断线保留“提交结果待核对”，不把 HTTP 400 当成上游未生成的证明。
- OpenAI 已有任务保留原结算快照；Grok/Ark 的记录随原查询和下载流程更新，不接管原有结算。记录更新暂时失败不会阻断原有扣费流程。
- 原生记录不交给 OpenAI 结算工作器；未来到期时间同时保护仍在运行的旧版本。没有新增数据库结构或价格变更。
- 已有明确限流及提交前凭据失败保留原有有界换号；其他提交异常不盲目重试，避免重复生成。
- 已核验的历史使用记录可按 usage_log_id 单条回填；脚本只插入已完成任务，不写余额或费用。

验证：后端构建、全量 unit、视频专项 race；前端类型、lint、344 文件/2547 测试；404 项定制守卫及守卫自身 6 项测试。服务器独立 PostgreSQL 验证未知提交、任务 ID 关联、状态更新、重复回写、身份冲突、原结算快照保留及旧工作器隔离。历史回填连续执行两次，只新增一条任务，使用记录和余额不变。
