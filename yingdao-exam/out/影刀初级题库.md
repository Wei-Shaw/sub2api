**备注：** 坑：“按商品名称写入对应 Sheet 页”要先用 IF/多分支把商品名映射到 Sheet 名，别写死。

### 86. [O005] 题型E·判断状态回写已发货（最常抽到）

1. 手动下载“待查询表格.xlsx”
　　2. 打开“待查询订单.xlsx”
　　3. 打开影刀商城订单管理页
　　4. 循环查询 Sheet1 中所有订单编号：搜索当前订单号 → 判断查询结果中“状态”是否为“完成”，若是则做“确认发货”并确认 → 在 Sheet1 当前循环行 B 列写入“已发货”或“未发货”
　　5. 关闭网页，保存并关闭 Excel

**答案：搭建要点：启动Excel → 循环Excel内容（A列订单号）→ 填写订单号+查询 → IF 状态文本=“完成” → 点击确认发货+点确定 → 写B列“已发货” / Else 写“未发货” → 循环结束关闭网页+保存关闭。**　`多源一致`

**备注：** 这是出现频率最高的一题。坑：①B列写入要用当前行号定位，别覆盖整列；②写入方式选“覆盖”不是“追加”；③提交前确认影刀客户端停在初始界面。

### 87. [O006] 题型F·登录+抓取+倒序删除

1. 打开影刀商城登录页
　　2. 输入账号 admin1、密码 admin1 并登录
　　3. 进入“订单管理”
　　4. 【批量数据抓取】获取所有订单及信息
　　5. 新建 Excel 到桌面，写入抓取数据
　　6. 循环 Excel 每行，把“状态”为“取消”的订单删除整行（Tip：倒序删除）
　　7. 保存并关闭表格
　　8. 退出登录状态，关闭网页

**答案：搭建要点：打开网页 → 填写账号密码+点击登录 → 点订单管理 → 批量数据抓取（所有页）→ 新建Excel+写入 → 从最后一行往上循环（倒序）→ IF 状态=取消 → 删除行 → 保存关闭 → 退出登录。**　`多源一致`

**备注：** 核心考点就是“倒序删除”：正序删行会导致后续行号错位，必须从末行往首行循环。
